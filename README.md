# 🔐 Personal Secure Vault

A Python-based desktop application for securely storing and managing files using password-derived encryption and Fernet cryptography.

## ✨ Features

- 🔑 Password-protected vault
- 🔐 Fernet-based file encryption
- 🛡️ PBKDF2-HMAC key derivation
- 📁 Secure file storage
- 📤 Decrypt and export files
- 🗑️ Delete files from the vault
- 🔒 Lock and unlock vault
- 📋 View stored files, size and file type
- 🖥️ Simple Tkinter graphical interface

## 🛠️ Technologies Used

- Python
- Tkinter
- Cryptography
- Fernet
- PBKDF2-HMAC
- SHA-256
